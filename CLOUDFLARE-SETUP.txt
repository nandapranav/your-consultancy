FIFTH CURSOR - CLOUDFLARE PAGES SETUP

This project intentionally uses standalone HTML capability pages instead of React routing.

Cloudflare Pages build settings:
Framework preset: Vite
Build command: npm run build
Build output directory: dist
Root directory: / (leave blank)

The home page buttons point directly to:
/capabilities/ai-strategy-transformation.html
/capabilities/cloud-architecture.html
/capabilities/ai-engineering.html
/capabilities/modernization-migration.html
/capabilities/data-platforms.html
/capabilities/intelligent-automation.html

IMPORTANT:
- Do NOT add a public/_redirects file containing /* /index.html 200.
- Commit/push the entire project, including public/capabilities/*.html.
- After pushing, trigger a NEW Cloudflare Pages deployment.
- Vite copies everything in public/ into dist/, so the six HTML files will be deployed as real static files.

If Cloudflare is using a Wrangler deploy instead of Git integration:
1. npm install
2. npm run build
3. npx wrangler pages deploy dist --project-name=your-consultancy
